<h1>🚀 Projeto – Tela de Login</h1>

<p>
Projeto desenvolvido durante a disciplina de <strong>Programação Front-End</strong> na
<strong>UniCesumar (Campus de Londrina)</strong>, com orientação do professor
<strong>Leonardo Rocha</strong>.
</p>

<p>
O objetivo da atividade foi compreender conceitos iniciais do desenvolvimento web moderno,
utilizando <strong>Bootstrap</strong> para construção da interface e
<strong>Git</strong> para controle de versão do projeto.
</p>

<hr>

<h2>📚 O que aprendi</h2>

<p>
Durante as aulas foram apresentados conceitos fundamentais importantes
para o início na área de desenvolvimento web.
</p>

<h3>Frameworks Front-End</h3>

<p>
Aprendi o conceito de frameworks e como eles ajudam a acelerar o desenvolvimento
de interfaces modernas e responsivas.
</p>

<p>Neste projeto foi utilizado o <strong>Bootstrap</strong>, explorando:</p>

<ul>
<li>Estrutura do framework</li>
<li>Componentes prontos de interface</li>
<li>Exemplos disponíveis na documentação oficial</li>
</ul>

<p>
A base do projeto foi o template <strong>Sign-in</strong> disponibilizado
na própria documentação do Bootstrap.
</p>

<hr>

<h2>💻 Versionamento de Código</h2>

<p>
Também foram introduzidos conceitos de versionamento utilizando
<strong>Git</strong>, ferramenta essencial no desenvolvimento de software.
</p>

<p>Aprendi a:</p>

<ul>
<li>Configurar o ambiente de desenvolvimento</li>
<li>Acompanhar alterações no projeto</li>
<li>Organizar versões do código</li>
<li>Enviar alterações para um repositório remoto</li>
</ul>

<h3>Comandos aprendidos</h3>

<ul>
<li><strong>git help</strong> – Mostra a lista de comandos disponíveis.</li>
<li><strong>git status</strong> – Lista arquivos novos ou modificados.</li>
<li><strong>git add [arquivo]</strong> – Adiciona um arquivo específico.</li>
<li><strong>git add .</strong> – Adiciona todos os arquivos modificados.</li>
<li><strong>git config --global user.name</strong> – Define o nome dos commits.</li>
<li><strong>git config --global user.email</strong> – Define o email dos commits.</li>
<li><strong>git commit -m "mensagem"</strong> – Salva as alterações.</li>
<li><strong>git push</strong> – Envia commits para o repositório remoto.</li>
</ul>

<h2>🧩 Sobre o Projeto</h2>

<p>
Foi proposta a criação de uma <strong>tela de login</strong> utilizando Bootstrap.
</p>

<p>A interface permite que o usuário:</p>

<ul>
<li>Insira seu endereço de e-mail</li>
<li>Digite sua senha</li>
<li>Utilize a opção <strong>"Lembre-me"</strong></li>
</ul>

<p>Além disso, o projeto inclui:</p>

<ul>
<li>Botão de FAQ interativo</li>
<li>Perguntas frequentes para ajudar usuários</li>
<li>Interface responsiva</li>
</ul>
