# 💻 Projeto - Tela de Login

Projeto desenvolvido na disciplina de Programação Front-End, na Unicesumar (Campus de Londrina).

Durante as aulas, o professor [Leonardo Rocha](https://github.com/leonardossrocha) apresentou os conceitos fundamentais de frameworks, com foco no Bootstrap, explorando sua estrutura, principais componentes e exemplos práticos disponibilizados pela própria documentação do framework.

Também foram abordados conceitos de versionamento com Git, incluindo a configuração do ambiente de desenvolvimento e a execução passo a passo dos comandos essenciais para controle de versão e organização do projeto.
